# 🛒 E-Commerce Website

A modern and responsive E-Commerce Website built using HTML, CSS, and JavaScript. This project allows users to browse products, view product details, add items to the cart, and enjoy a seamless shopping experience.

## 🚀 Features

* Responsive design for all devices
* Modern and attractive UI
* Product listing section
* Product details page
* Shopping cart functionality
* Add and remove products from cart
* Dynamic price calculation
* Search and filter products
* Smooth animations and transitions

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
